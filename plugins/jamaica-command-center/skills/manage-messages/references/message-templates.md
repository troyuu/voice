# Message Templates

## Clear reply

```text
Hi [Name],

[Direct answer or key update].

[Needed detail or next step]. Please [action] by [date/time] if applicable.

[Sign-off]
```

## Ask for missing information

```text
Hi [Name],

Thank you for the update. To move this forward, could you please send [specific information]?

Once I have it, I can [next action].

[Sign-off]
```

## Polite follow-up

```text
Hi [Name],

I'm following up on [topic]. Could you let me know [specific status or action] by [date]?

Thank you,
[Sign-off]
```

## Decline without closing the relationship

```text
Hi [Name],

Thank you for [offer/request]. We won't be able to [declined action] at this time because [brief reason, only if approved].

[Alternative or future next step, if appropriate].

[Sign-off]
```

## Call follow-up

```text
Hi [Name],

Thank you for speaking with me today. We agreed that:

- [Decision or commitment]
- [Owner and due date]

The next step is [next action]. Please let me know if I missed anything.

[Sign-off]
```
