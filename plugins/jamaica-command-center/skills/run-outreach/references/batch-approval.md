# Batch Approval and Report

## Approval card

```text
Batch ready for approval

Channel and sender: [value]
Audience: [source and recipient count]
Excluded: [duplicates, opt-outs, invalid, other]
Subject: [email only]
Message: [exact final content]
Personalization: [fields and fallbacks]
Links/attachments: [list or none]
Schedule: [date, time, timezone]
Opt-out handling: [method]
Important note: [risk or none]

Approve this exact batch?
```

## Delivery report

```text
Result: [completed, stopped, or partially completed]
Attempted: [count]
Sent: [count]
Delivered: [count or not available]
Failed: [count]
Skipped: [count and reason]
Opt-outs: [count]
Needs review: [concise issue or nothing]
```
